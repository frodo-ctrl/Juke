# Juke(剧刻) 品牌启动页 · 实现交接规格书

> 本文件是启动页视觉方案的唯一实现依据。配套文件（同目录）：
> - `preview.png` —— 最终视觉效果图（验收对照基准）
> - `index.html` / `styles.css` —— 高保真原型与完整 Design Tokens（styles.css 顶部注释为令牌总表）
> - `assets/bg.jpg` —— 背景图（AI 生成的虚构海报墙，无版权风险，直接打包进 App）
>
> 要求：实现效果必须与 `preview.png` 一致。任何参数以本文件与 styles.css 令牌为准，不得自行发挥。

## 1. 需求概述

- App 启动时先显示品牌启动页，停留约 1.5~1.8s 后自动进入主界面。
- 页面无任何按钮、无跳过、无加载进度条、无版本号。
- 不依赖任何网络请求，弱网/离线也立即显示。
- App 显示名称改为 `Juke`（manifest label），启动页内同时展示中英文品牌名。

## 2. 画面结构（自底向上图层顺序）

1. **背景图层**：`assets/bg.jpg`，`centerCrop` 铺满；模糊 3px、饱和度 1.1、放大 1.04 倍（遮盖模糊白边）。
2. **压暗叠加层**（保证文字可读，同时让海报墙清晰可辨）：
   - 中央文字区暗 scrim：径向渐变，中心 (50%, 52%)，半径约 70%x46%，`rgba(20,20,20,0.42)` → 55% 处 `0.2` → 78% 处透明。
   - 整体轻压暗：顶部 `rgba(67,71,76,0.18)` → 中部 `rgba(55,55,55,0.26)` → 底部 `rgba(43,43,43,0.35)` 的径向渐变，再叠一层垂直线性渐变 `rgba(43,43,43,0.05 → 0.3)`。
3. **暗角**：径向渐变，58% 以内透明，边缘 `rgba(0,0,0,0.25)`。
4. **胶片颗粒**：噪点纹理，不透明度 0.05（可选，性能敏感可省略）。
5. **状态栏**：透明背景、浅色图标（系统处理）。
6. **品牌文字区**（垂直居中、整体略偏上，底部留 48dp）：三行文字，见 §3。
7. **Home 指示条**：系统手势条，浅色（系统处理）。

**禁止出现**：加载进度条、胶片齿孔装饰、品牌名两侧横线、顶部图标等任何额外装饰元素。

## 3. 文字规格（三行，全部水平居中）

| 元素 | 内容 | 字体 | 字号 | 字距 | 颜色 | 其他 |
|---|---|---|---|---|---|---|
| 英文词标 | `Juke` | 衬线斜体（Georgia 风格；Android 用系统 serif + italic，或内置开源衬线斜体如 Playfair Display Italic） | 46sp | 3 | 纯白 `#FFFFFF` | 白色柔光：shadow 半径 18、`rgba(255,255,255,0.28)` |
| 中文品牌名 | `剧刻` | Noto Serif SC **900**（内置 res/font） | 18sp | 12 | `#F8FDFF` | 粗宋体碑刻感 |
| 口号 | `好剧 从此刻开始` | Noto Sans SC **200**（内置 res/font） | 13sp | 8 | `rgba(248,253,255,0.62)` | 极细无衬线；**中间是空格、无逗号**，文案一字不改 |

行间距：`Juke` → `剧刻` 20dp；`剧刻` → 口号 28dp。

字体许可：Noto Serif SC / Noto Sans SC 为 SIL OFL 开源字体，可商用内置；从 Google Fonts 下载对应字重子集即可。

## 4. 色彩令牌（与项目默认深色主题对齐，来源 Colors.kt）

- 背景基准 `#373737`（md_theme_dark_background）
- 表面/光晕 `#43474C`（md_theme_dark_surface）
- 主文字 `#F8FDFF`（md_theme_dark_onSurface）
- 次级文字 `rgba(248,253,255,0.62)`
- 强调色 `#FDC704`（md_theme_dark_accent）——**启动页当前未使用强调色**，不要加金色元素

## 5. 入场动效

- 三行文字错峰淡入 + 上移 14dp：单元素时长 620ms，曲线 `cubic-bezier(0.21, 0.61, 0.35, 1)`。
- 延迟序列：`Juke` 0s → `剧刻` 0.14s → 口号 0.30s。
- 总入场约 0.92s；页面停留 1.5~1.8s 后自动跳转主界面（用固定延时，不等待网络）。
- 系统开启"移除动画"（减少动态效果）时：跳过入场动画直接显示静态画面。

## 6. Android 落地要点

1. **系统启动页衔接（Android 12+ SplashScreen API）**：`windowSplashScreenBackground` 设为 `#373737`，`windowSplashScreenAnimatedIcon` 用简化白色 `Juke` 字标或纯文字图标，避免系统页与品牌页出现两块割裂画面。
2. **品牌页载体**：独立 Activity 或主 Activity 内的首屏 Compose 界面均可；背景与文字层按 §2 顺序用 Box 堆叠。
3. **背景模糊实现**：优先 API 31+ `RenderEffect.createBlurEffect`（Compose `Modifier.blur(3.dp)`）；低版本直接打包一张预模糊好的 bg.jpg 兜底（即当前 assets/bg.jpg 本身已带轻度模糊，可不再运行时模糊）。
4. **字体内置**：`res/font` 放入 Noto Serif SC 900、Noto Sans SC 200 子集文件；词标用 `FontFamily.Serif + FontStyle.Italic`。
5. **状态栏/导航栏**：透明 + 浅色图标（`WindowCompat` / `enableEdgeToEdge`）。
6. **应用名**：`app_name` 改为 `Juke`。

## 7. 验收标准

- 与 `preview.png` 逐层对照：背景海报墙轮廓与色彩可辨识（不能糊成纯黑）、三行文字清晰、无进度条、无多余装饰。
- 冷启动离线状态下 1.8s 内完成展示并进入主界面，无白屏/闪跳。
- 系统深色/浅色模式、不同主题（Aqua/Amber 等）下启动页表现不变（固定使用本规格色值）。
